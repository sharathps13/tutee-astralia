# Tutee Connect — Australia landing page

A faithful clone of the deployed reference site (`https://pageus.netlify.app/#/`),
localised for Australia. Same layout, same Tailwind classes, same scroll and
hover animations; only the copy, the photographs and the institution directory
change. Built 2026-09-01, the sixth country page after the UK, Canada, Ireland,
Germany and New Zealand.

## Files

```
index.html               the landing page          (generated)
universities.html        the directory page        (generated)
assets/css/main.css      the reference's compiled stylesheet, shipped verbatim
                         apart from the australia-city.jpg image key
assets/js/main.js        interactions              (generated by localise_au.py)
assets/js/services-data.js  the nine service tabs  (generated by localise_au.py)
assets/js/universities-data.js  1,258 CRICOS providers (generated by
                         build_dataset_au.py)
assets/img/photos/       four Australian photographs — see CREDITS.md
api/enquiry.py           the enquiry → email function (installed from _tooling)
serve.py                 local preview server
Start Local Server.command   double-click to preview
```

**Everything above marked "generated" is overwritten by the next build.** Edit
the source in `../_tooling/`, never the built file. That mistake has already
cost one silent regression on the UK page.

## How it was built

```bash
cd "../_tooling"

python3 build_dataset_au.py           # CRICOS snapshot -> universities-data.js
python3 build_dataset_au.py --refresh # ...re-downloading the register first
python3 localise_au.py                # fragments-australia/ + main.js + services-data.js
python3 assemble.py australia         # index.html
python3 build_unipage.py australia    # universities.html
python3 verify_site.py australia      # every check
python3 devserver.py australia        # serve it with a working /api/enquiry
```

The content mapping — visa names, work rights, money, language tests, the
documents in the file — is written down in `../_tooling/AUSTRALIA_SPEC.md`.
Read that before changing any copy; several UK sentences map onto Australian
things that were renamed between 2024 and 2026 and are easy to get subtly wrong.

The `.reveal` animation is driven by `IntersectionObserver`, which **does not
fire in a hidden or backgrounded browser pane**, and CSS transitions are frozen
there too. If the reveals look broken while automating a browser, check
`document.visibilityState` before believing it — the UK page behaves identically
under the same conditions.

## No DOM-text divergence

This is the first localised page with **none**. New Zealand had to rewrite the
badge on carousel cards 9–12 because it has only eight universities and the
reference DOM hardcodes twelve `Rank #N` badges. The QS World University
Rankings 2026 cover **36** Australian institutions, so cards 1–12 carry
`Rank #1`–`Rank #12` exactly as the reference site does and the heading stays
"Top Ranked Universities". `localise_au.py` asserts that the first twelve
dataset entries are all genuinely ranked, so a future register or ranking change
cannot quietly reintroduce a fabricated position.

## Deliberate divergences from the UK page

1. **`capacity` replaces `offerRate`.** The UK page's acceptance-rate percentages
   are invented placeholders and remain a launch risk there. That card slot here
   carries the provider's **registered overseas-student capacity** off CRICOS —
   a real published figure. Card label: **"CRICOS capacity"**. It is a
   registration ceiling, **not** an enrolment count and **not** a measure of
   selectivity; never relabel it as either.
2. **`swap_currency: False`.** Australia uses dollars, so the reference site's
   own lucide dollar icons are correct and are left untouched — as for Canada
   and New Zealand. That setting only covers the HTML: `services-data.js` ships
   its icons inline and the UK file holds the pound glyph, so `localise_au.py`
   swaps it back and asserts no pound glyph survives. **Canada never did this and
   still renders a £ icon on a dollar page.**
3. **`programs` is real.** Every previous country page fell back on an editorial
   subject descriptor. This one uses the three commonest **fields of education**
   across the provider's live registered courses, taken from the register's own
   ASCED classification.
4. **`alt` is searched but never rendered.** The register holds legal institution
   names, so without it the directory could not be searched by "UNSW", "UQ",
   "ANU", "RMIT" or by a campus city. It carries the register's own trading names
   and campus localities plus a small table of well-known initialisms. No
   diacritic folding is needed — unlike Canada, Germany and New Zealand, nothing
   in this register carries an accent.
5. **Australian spelling: `program`, not `programme`** (`-ise` endings stay).
   `verify_site.py` treats `programme` as a leak for this country only.
6. **Family is the headline, not a footnote.** Australia is the most generous of
   the six: the partner and children under 18 go **into the student's own
   subclass 500 application**, and the partner's work cap lifts entirely once the
   student is enrolled in a master's or a doctorate. The `#relocate` section and
   FAQ Q4 lead with that. Do not "restore" the UK's research-students-only rule.

## The dataset

`assets/js/universities-data.js` holds **1,258 providers** from the
**Commonwealth Register of Institutions and Courses for Overseas Students
(CRICOS)**, published as open data at data.gov.au (dataset
`e5ae7059-bfa8-4fa4-a5c0-c13cf3520193`). A vendored snapshot lives at
`../_tooling/reference/cricos-providers.json` so a rebuild is deterministic and
offline; `--refresh` re-downloads the three CSV extracts.

**Why the register needs no editorial filtering.** Under the ESOS Act 2000 a
provider may not offer a course to a student-visa holder unless both the
provider and the course are on CRICOS, and the Confirmation of Enrolment a
subclass 500 application is built on can only be issued against a CRICOS course
code. Being listed is *exactly* the permission the cards state as
`Intl. Admits: Yes`. New Zealand reached the same place with a Code-of-Practice
filter; CRICOS goes further, because it also publishes a real per-provider
statistic and the full course inventory — which is why nothing on this page is
an invented per-institution number.

**Two exclusions, and only two:** providers with no live registered course (5),
and providers whose only live courses are compulsory schooling (243). The second
is the Germany lesson — the directory is headed "universities and colleges" and
the copy around it addresses an adult applicant to a tertiary course, so a
grammar school would be misdescribed by fixed copy it cannot answer for. A
provider offering school courses *alongside* tertiary ones is kept.

- **Flagship group:** the Group of Eight (8 members).
- **Types:** `Group of Eight` (8), `University` (34 — TEQSA's Australian
  University category), `Higher Education` (136), `Vocational` (952),
  `English & Pathway` (128). The last three come from the highest AQF level the
  provider holds a live course in. **Trap:** 482 providers hold a Graduate
  Diploma or Certificate but no degree — those are the VET sector's *vocational*
  graduate awards, so the builder counts a graduate award as higher education
  only alongside a degree.
- **Ranked:** entries 1–36 are the QS World University Rankings 2026 in QS
  order. Everything after is `ranked: false` and shows a dash.
- **Adelaide University is a merger, not a rename** — the University of Adelaide
  and the University of South Australia combined on 29 January 2026. Both old
  names are in `alt`, so a search for "UniSA" still finds it.
- **Duplicate registrations are merged.** 37 rows collapse into their parent
  institution (the University of Southern Queensland and Victoria University each
  hold two CRICOS registrations); their capacities add and their courses and
  campuses are unioned.

## Known issues to settle before launch

1. **Every figure in the copy is dated.** Australian migration settings move
   faster than any other destination on these pages: the visa charge (A$2,500),
   the 485 charge (A$5,750), the Core Skills Income Threshold and the minimum
   wage (A$26.44/hr, A$33.05 casual) all changed on **1 July 2026**, and the
   A$29,710 financial-capacity figure is indexed separately. Re-check all of them
   against `immi.homeaffairs.gov.au` and `fairwork.gov.au` before any intake.
2. **The CRICOS snapshot is dated 2026-09-01.** The register is republished
   monthly and providers enter and leave it. Re-run `--refresh` before launch;
   the builder asserts every TEQSA university is still present, so a rename or a
   merger fails the build rather than silently demoting an institution.
3. **125 institution names are ALL CAPS**, because that is how their operators
   registered them. They are the registered legal names and have deliberately
   not been re-cased — re-casing would wreck genuine acronyms such as `TAFE SA`
   and `IIBIT AHE`. Decide whether the client wants a hand-curated casing table.
4. **All four photographs are CC BY**, so the footer credit line is a **licence
   obligation**, not a courtesy. Do not remove the `data-photo-credit` element.
   See `assets/img/photos/CREDITS.md`.
5. **The QS 2026 ranks were transcribed from a secondary source** (a rankings
   aggregator, cross-checked against Charles Darwin University's own release for
   its 584 placing). Verify against QS directly before launch if the client
   wants the ranks warranted.
